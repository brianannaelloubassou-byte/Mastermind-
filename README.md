# 🎯 Mastermind en Python

## 📌 Description

Mastermind est un jeu de logique développé en Python dans lequel le joueur doit retrouver une combinaison secrète de couleurs ou de chiffres en un nombre limité de tentatives. Après chaque proposition, le jeu fournit des indices permettant d'aider le joueur à deviner la combinaison correcte.

## ✨ Fonctionnalités

- Génération aléatoire d'une combinaison secrète.
- Saisie des propositions du joueur.
- Vérification des propositions.
- Affichage d'indices pour aider à trouver la combinaison.
- Nombre de tentatives limité.
- Détection de la victoire ou de la défaite.

## 🛠️ Technologies utilisées

- Python 3

## 🚀 Installation et lancement

1. Cloner le dépôt GitHub.
2. Accéder au dossier du projet.
3. Lancer le jeu avec la commande suivante :

```bash
python mastermind.py
```

## 🎯 Objectif du projet

Ce projet permet de mettre en pratique les bases de la programmation Python, notamment les conditions, les boucles, les fonctions, les listes et la génération aléatoire, tout en développant la logique et la réflexion.
